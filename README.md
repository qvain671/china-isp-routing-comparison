## 先搞懂 AS4837 和 AS9929 各是什么

**AS4837** 就是大家熟知的联通 169 网，也叫 CHINA169。这张网的历史可以追溯到 1996 年，最初是中国公众多媒体通信网，2008 年中国联通与网通合并后正式归入联通旗下。现在联通家宽的国际出口走的基本都是这条路。

**AS9929** 是联通的 A 网，也叫联通 IP 承载 A 网。前身是网通时代建设的独立网络 CNCNET，负载历来比较低，主要用于服务政企客户，被联通内部称为 China Unicom Premium IP Transit（简称 CU Premium 或 CUP）。路由节点 IP 通常以 218.105 或 210.51 开头，看到这两个开头基本可以确认在走 AS9929。

两者最核心的区别在于：AS9929 **只存在于国内段**，一旦出境就会并入 AS4837 或者联通国际 AS10099。换句话说，所谓走 AS9929 回国的线路，完整路径是——服务器 → 联通香港国际出口（AS10099）→ 国内联通 A 网（AS9929）→ 各地运营商。

---

## 两者到底差多少？

结论先说：**AS9929 的线路质量整体优于 AS4837，但优势并不是绝对的**。

从路由结构来看，AS4837 的 VPS 走的是联通普通骨干网国际出口，晚高峰压力比较大，过去几年因为上车的用户越来越多，表现逐渐不如刚出来时稳定。AS9929 走的是联通香港的 AS10099 出口，跨境段绕开了 AS4837 拥堵的国际出口，所以在晚高峰的稳定性上有优势。

实际用下来，联通用户的感受会比电信和移动用户更明显——因为 AS9929 本身就是联通的 A 网，回程路由对联通用户更友好。电信用户走 AS9929 能绕过部分跨网拥堵，效果也不错，但不如走 CN2 GIA 来得直接。

还有个代价：AS9929 的带宽成本比 AS4837 贵得多（大约贵五倍以上），所以市面上卖 AS9929 线路的 VPS，带宽和流量通常给得比较少，价格也更高。这也是为什么 AS9929 的容量偏小，晚高峰容易出现拥堵——大家都知道它好，所以往里挤。

总结一句话：**AS9929 线路质量 > AS4837，但 AS9929 产品的性价比不一定 > AS4837 产品**。要看具体商家的带宽配置和定价。
